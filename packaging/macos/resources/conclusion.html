Eggie is installed, but it has nothing to run yet.

Open Eggie from your Applications folder to build the virtual machine. It downloads a Linux image and installs Docker inside it, which takes several minutes on a first run.

If you prefer the terminal, eggie setup --headless does the same thing and prints its progress.

To remove everything later, including the virtual machine and every project inside it, run eggie uninstall --purge and then drag Eggie to the Trash.
